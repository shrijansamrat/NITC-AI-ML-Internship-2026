# 🔋 NIT Calicut AI-ML Summer Internship 2026

## Deep Learning Based Battery State Estimation Across Multiple Lithium-Ion Battery Chemistries

This repository contains all the work completed during my **AI-ML Summer Internship 2026** at the **Department of Electrical Engineering, National Institute of Technology Calicut (NITC)** under the guidance of **Dr. Nimal Madhu M**.

The internship focused on developing a unified deep learning framework for **Battery State Estimation** across multiple lithium-ion battery chemistries using **Long Short-Term Memory (LSTM)** and **Gated Recurrent Unit (GRU)** neural networks.

# 🎯 Objectives

- Study multiple lithium-ion battery chemistries.
- Develop a common deep learning framework for battery state estimation.
- Compare the performance of LSTM and GRU models.
- Evaluate model generalization across heterogeneous battery datasets.
- Investigate the applicability of lightweight deep learning models for future Edge-AI deployment.
